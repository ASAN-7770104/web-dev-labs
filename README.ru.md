# Лабораторные по веб-разработке

[English](README.md) · **Русский**

Небольшие упражнения из учебных курсов.

| Папка | Что это | Технологии |
|---|---|---|
| `weather-api` | текущая погода из OpenWeatherMap | Express, Axios |
| `name-generator` | генератор названий групп | Express, EJS |
| `slugify-demo` | работа с пакетом npm | Node.js, slugify |
| `design-studio-landing` | посадочная страница | HTML, CSS, Bootstrap 5 |
| `first-frontend-page` | первая фронтенд-страница | HTML, CSS, JavaScript |

Для папок с Node: `npm install`, затем `node index.js` (или `node app.js`). Для погоды нужен свой ключ:
`OPENWEATHER_API_KEY=... node app.js`.
